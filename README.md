- `rss.xml` — 매거진 3편 RSS 2.0 피드 (메인 `<head>`에 `rel="alternate"` 링크)

- `robots.txt` — 전체 허용, Naver Yeti·Googlebot·Bingbot 명시, sitemap 안내

- 소유확인 메타태그는 메인에만 있으면 됩니다(사이트 단위 확인). 네이버 `5d6aff7e…`, 구글 `Yj5bsX9E…`
